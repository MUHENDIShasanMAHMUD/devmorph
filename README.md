# ⚡ DevMorph | Modern Developer Utility Hub

> Fast, private, and 100% offline client-side developer utility suite. Zero data leaves your browser.

🔗 **Live Tool:** [https://tools.hasantechlab.com](https://tools.hasantechlab.com)  
🌐 **Main Portfolio:** [https://hasantechlab.com](https://hasantechlab.com)

---

## 🛠️ Features

- **JSON ➔ TypeScript Interfaces:** Automatically infers types, nested structures, and arrays.
- **JSON ➔ Go Structs:** Generates clean Go structs with correct `json` tags and numeric type handling (`int` vs `float64`).
- **cURL ➔ Fetch:** Transforms multi-line cURL commands into modern, clean JavaScript `fetch()` syntax.
- **JWT Decoder:** Inspects and validates JSON Web Tokens directly in your browser without security risks.
- **JSON Minifier / Prettifier:** Format or compress JSON payloads with zero lag.
- **Drag & Drop / File Upload:** Directly import configuration or JSON files.
- **Instant Export:** Download generated code as `.ts`, `.go`, or `.js` with a single click.

---

## 🔒 Security & Privacy

DevMorph runs entirely **client-side**. No requests, credentials, tokens, or payloads are sent to external servers or logged in any backend.
